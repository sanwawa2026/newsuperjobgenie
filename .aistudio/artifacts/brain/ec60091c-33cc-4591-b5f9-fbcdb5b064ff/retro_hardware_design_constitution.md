## 🏛️ 第一章：核心设计图腾与绝对铁律（不可违背）

### 1. 右上角 GoldStar CRT 彩色监视器与复古人视频
* **唯一指定正统视频**：
  - 路径：`/assets/aistudio/___8s_d10be03c.mp4`
  - 规格：1920×1080 30FPS，8.13秒完美自然循环转头、粉光荧光眼、毛呢西装灰背景。
  - **红线禁令 1（严禁嵌套套娃）**：绝对禁止将用户的操作录屏、网页截屏（如 `1024_b2e6a274.mp4`）当作素材塞入电视机！否则会出现“电视机里套网页、网页里又有电视机、中间顶着巨大白播放键”的滑稽灾难。
  - **红线禁令 2（严禁错位跳跃）**：绝对禁止私自用 ffmpeg 乱切帧生成左右瞬移、半张脸消失的劣质 4 秒抽搐片！
* **CRT 视效标准**：
  - 包含经典隔行扫描线（`SCANLINES ON/OFF` 切换开关）；
  - 左上角绿光指标：`LIVE SIGNAL · ARTIFACT CLEANED`；
  - 右下角橙色角标：`FIT: 97%`；
  - 底部 GoldStar 标识与绿光 `LOCK` 指示灯。

### 2. 响应式布局铁律（防“右侧不见了”）
* **布局容器**：
  - `src/components/IndustrialHero.tsx` 主栅格必须使用：
    ```tsx
    <div className="grid grid-cols-1 md:grid-cols-12 gap-6 lg:gap-10 py-6 sm:py-8 items-center">
    ```
  - 左侧文案：`md:col-span-7 flex flex-col justify-center`
  - 右侧控制台：`md:col-span-5 flex justify-center w-full`
* **红线禁令 3（防断点断层）**：
  - 绝不允许仅用 `lg:grid-cols-12`！在 AI Studio 侧边栏开启、预览窗口为 800~950px 的中等宽度下，仅用 `lg:` 会强制将右侧控制台掉到页面最底部，造成用户视角的“右侧网页不见了”。必须以 `md:`（768px）作为并排基准！

## 🛡️ 第二章：防小鬼作祟自动化校验工作流（Checklist）

每次任何后续迭代、修复或代码调整时，必须强制对照本检查表：

| 校验项 | 正确标准 | 错误现象（立即报警阻止） |
| :--- | :--- | :--- |
| **电视机视频源** | `/assets/aistudio/___8s_d10be03c.mp4` | 变成截屏、带巨大白 Play 按钮、或左右瞬移抽搐 |
| **右侧控制台位置** | 与左侧 Headline 并排在右上角 (`md:grid-cols-12`) | 掉到页面底部或右侧留白消失 |
| **复古人画面居中** | 居中稳坐，优雅转头 | 半边脸被切、忽高忽低、飘来飘去 |
| **机箱五金细节** | 4颗金属螺丝、散热格栅、GoldStar 铭牌在位 | 变成了千篇一律的通用纯黑暗黑模板卡片 |
| **Chrome 商店链接** | 官方 Chrome Web Store 永久有效链接 | 变成了假的未连接占位按钮 |
