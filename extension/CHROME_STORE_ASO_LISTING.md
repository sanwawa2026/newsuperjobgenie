## 4. 24 小时验证法则（按酸人的指引检查）
1. 提交更新后等待 Chrome 审核通过并上线生效（通常数小时到 24 小时）。
2. 打开 Chrome **无痕模式窗口（Incognito）**，确保避开你自己的浏览记录和已安装插件缓存。
3. 进入 Chrome Web Store 搜索框：
   - 搜 `resume matcher` -> 翻前 3 页找 SuperJobGenie
   - 搜 `cover letter generator` -> 翻前 3 页找 SuperJobGenie
   - 搜 `104 人力銀行` -> 检查是否出现在插件搜索结果中
   - 搜 `CakeResume` -> 检查是否出现在插件搜索结果中
4. 能在搜索结果前几页搜到，就意味着 **“被动引流通道” 已经彻底打开，从此睡觉都在自动吃自然搜索增量！**
